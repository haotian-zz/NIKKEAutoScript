# 独立推图实例

调度任务为「推图 → 自动推图」（`AutoPush`），与日常任务分开配置；原有工具「自动主线」与「自动收集品」保留。

## 使用步骤

1. 新建或复制 PC 实例，关闭其他任务，仅启用「自动推图」。重启任务默认仍开启，可以按实例关闭。
2. 地图类型选择「主线地图」，目前支持普通主线。
3. 选择「推图模式」：
   - **持续推图（当前主线）**：从当前主线任务进度开始，有确认进展就继续，直到无法推进、战败或恢复失败。该模式隐藏「开始章节」，保留的章节设置不参与执行。
   - **单轮推图**：保留原有单段预算；「开始章节」可选当前进度或第 1～50 章，进入后继续尚未清除的敌人。
4. 点击本页「开始推图」立即执行，不必改下次运行时间；实例总览的「启动」按原有排期执行。共享启动检查会打开游戏并完成登录。
5. 程序先回大厅，通过右上角主线任务箭头进入地图，自动切换 1776×999。单轮指定章节时逐章切换并核对 NORMAL 章节标识，未解锁则停止。
6. 在「执行记录」查看累计确认清除数、停止原因与补做入口。设置页保留「推图信息」及日志；用户可以随时停止。任务结束后恢复 720×1280。

## 持续执行与停止条件

每段仍有 48 次决策和 20 分钟预算。持续模式在本段有胜利结算确认的清除结果时，可以自动开始下一段；总执行时限只随确认进展续期。镜头移动、侦察或点击本身不会续期。单目标输入次数耗尽、战败或未知故障立即停止，不通过持续模式重置这些限制。

确认跨到下一普通章节时，先退出旧章执行器再按最新主线重新加载地图与坐标模型。没有可达目标时仅重新核对一次大厅任务；任务没有前进就停止，不在大厅和地图之间无限循环。定位失败最多恢复两次，首次恢复后仍无新清除就停止。

地图入口有 90 秒时限；单轮选择章节每步最多等 30 秒、总计六分钟。若大厅读不到「通关 x-y」类主线目标，会提示检查入口。地图定位仍受道路证据限制，恢复不能保证解决所有视野的配准问题。

简报只累计通过胜利结算确认清除的敌人，不把执行结束当作某关或整章通关。遇到受阻时保留本轮记录，可选择补做。

## 剧情优先处理

全局截图处理支持竖屏和 1776×999 横屏，地图、章节切换、战前战后出现已识别的 SKIP 都优先跳过。刚点击 SKIP 后，优先检查跳过确认框，要求文字同时包含跳过说明与确认按钮；不会把任意确认框当作剧情。

防抖期间继续截图，剧情帧不会因为超过四帧而交给地图导航。剧情处理最多等待 60 秒，15 秒保留等待截图，仍未关闭则停止并写入原因。跳过剧情和点击继续均不作为战斗胜利证据。

安装时需要在自带 Python 中执行 `toolkit\python.exe -m pip install -r requirements-yolo.txt`。输入前会检查识别运行时及模型，组件不全时在简报提示处理。

## 地图定位与耗时

配准会排除在面板内跨越投影地平线的参数：这类变换虽有有限角点，却会把道路折叠成碎片，产生高分伪候选，导致正确位置被判为歧义。道路重合度、候选分差及参数离散度标准保持不变。紧凑与展开面板分别缓存热启动参数，不混用或互相清除。

章节确认所得的紧凑地图定位结果直接作为第一次尝试；失败后展开补充新证据，不再对原视图重复搜索。推图窗口切换采用一秒稳定检查并核对实际客户区尺寸，其他任务继续使用原设置。

参数搜索最多四路并行，按原顺序合并候选，低核数设备自动减少并发。固定失败帧基准中配准由约 3.8 秒降至 1.3 秒，坐标、评分与拒绝结果相同。该测量只代表配准环节；首次 OCR 初始化、游戏加载和动画仍有各自耗时。
