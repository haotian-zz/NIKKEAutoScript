# 独立推图实例

调度任务为「推图 → 自动推图」（`AutoPush`），与日常任务分开配置；原有工具「自动主线」与「自动收集品」保留。

## 使用步骤

1. 新建或复制 PC 实例，关闭其他任务，仅启用「自动推图」。重启任务默认仍开启，可以按实例关闭。
2. 选择「地图类型 → 主线地图」。目前只支持普通主线，其他地图以后扩展。
3. 「开始章节」默认是「当前主线进度」；也可以选择第 1～50 章。进入该章后继续尚未清除的敌人，不需要填写具体关卡号。
4. 点击本页「开始推图」立即执行，不必改下次运行时间；实例总览的「启动」按原有排期执行。共享启动检查会打开游戏并完成登录。
5. 程序先回大厅，通过右上角主线任务箭头进入地图，再自动切换 1776×999 客户区。选择了指定章节时，通过相邻章节按钮切换，每次重新读取章节号，确认进入目标普通章节后才交给推图执行器。
6. 查看「执行记录」和设置页「推图信息」。停止原因、已确认清除数及日志会保留；需要补做时可在简报选择重试。结束后恢复 720×1280，供登录和日常使用。

## 执行与解锁限制

未解锁的章节无法进入，程序会停止并提示，不会在其他章节开始战斗。每次章节切换最多等 30 秒，整个选择过程最多六分钟；地图入口另有 90 秒时限。开始章节是保存的偏好，不是精确关卡传送，也不会重打已清除的敌人。

地图与小队确认后，执行器负责侦察、目标选择、移动、战斗、跳过剧情与结算。上游每段最多 48 次决策，并有单目标操作预算和 20 分钟时限。定位失败最多两次经大厅复位并重新选择章节；第一次恢复后仍没有新胜利就停止。战败、窗口变化等不会触发定位恢复。

定位不可信、道路不明、战败或预算耗尽时仍需复核。简报中的清除数只统计胜利结算确认的敌人，不代表已经完成某个关卡或整章；多段恢复后的确认数会合并。

## 操作优化

- 右上角主线任务引导避开大厅活动浮窗遮挡的作战入口。若读不到「通关 x-y」类主线目标，停止并提示检查。
- 登录与日常使用竖屏，推图自动切换尺寸，结束后恢复。
- 地图与开始章节设置排在资源和预览之前，启动按钮就在本页。
- 已有可达目标时先推进；没有明确目标时保留上游主线标记侦察。
- 各实例使用共享鼠标互斥，其他实例排期不因推图设置而改变。

安装时需要在自带 Python 中执行 `toolkit\python.exe -m pip install -r requirements-yolo.txt`。输入前会检查识别运行时及模型，组件不全时在简报提示处理。

实机记录中已确认普通第 20 章切到第 19 章再返回，也确认了快速战斗胜利后继续下一目标。部分视野的道路配准仍可能不可信；此时会有限恢复或停止，需要处理。尚不能把这一功能视为稳定通完整章的保证。
